# Pi-Gaze

Айтрекер на Raspberry Pi 5: ИК-камера над монитором следит за глазами, и курсор ПК идёт
туда, куда ты смотришь. Для ПК это обычная USB-мышь (CH9329), ставить на ПК ничего не нужно.

| Часть | Где | Проверка |
|---|---|---|
| Железо: тиски на монитор, бар с камерой и ИК-диодами, доработанный кейс Pi | [`hardware/`](hardware/README.md) | `hardware/check.sh` — контр-модель, 63 проверки |
| Программа: трекер глаз, калибровка, курсор | [`software/`](software/README.md) | `software/build_tests_windows.cmd` на ПК; на Pi тесты гоняет установщик |
| Решения и дизайн | [`docs/superpowers/specs/`](docs/superpowers/specs/) | — |

## Запуск с нуля

1. Напечатать и собрать железо: [`hardware/README.md`](hardware/README.md).
2. SD-карта: Raspberry Pi OS Lite 64-bit + файлы из `software/deploy/sdcard/` и папка
   `pigaze/` (= `software/`) в загрузочном разделе. Wi-Fi: вписать имя и пароль в
   `network-config` на карте (или подключить кабель).
3. Вставить карту, включить Pi. Первая загрузка сама соберёт и поставит программу и перезагрузится (~10 мин).
4. Сесть перед монитором и смотреть на курсор, пока идёт калибровка по 9 точкам. Дальше курсор
   следует за взглядом. Кнопка питания Pi: 1 нажатие — пауза, 2 нажатия — перекалибровка.
