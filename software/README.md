# Pi-Gaze — программа

Глаза двигают курсор ПК. Raspberry Pi 5 смотрит на глаза через ИК-камеру на баре, понимает,
куда на экране ты смотришь, и двигает мышь ПК через CH9329 (для ПК это обычная USB-мышь).
На ПК ничего ставить не надо.

Архитектура и решения: [`docs/superpowers/specs/2026-09-25-pigaze-software-design.md`](../docs/superpowers/specs/2026-09-25-pigaze-software-design.md).

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Первое включение | Pi сам собирает и ставит программу (~5–10 мин, нужен интернет), перезагружается |
| Сел перед монитором | через 2 с видимых глаз стартует **калибровка**: курсор по очереди встаёт в 9 точек — **смотри на курсор** (~19 с) |
| Удачная калибровка | курсор описывает кружок в центре; дальше курсор ходит за взглядом |
| Неудачная | курсор «трясёт головой» влево-вправо; старая калибровка остаётся |
| Кнопка питания Pi, **1 нажатие** | пауза / продолжить (в паузе мышь снова твоя) |
| Кнопка питания, **2 нажатия** | перекалибровка (сдвинулся, пересел, сменил освещение) |
| Кнопка питания, **держать** | выключение Pi |

Моргание и взгляд мимо экрана курсор не дёргают — он просто стоит. Клик взглядом
(задержка на месте 1,2 с) выключен по умолчанию: `dwell_click = 1` в конфиге.

## С ПК по SSH

```bash
ssh -i ~/.ssh/pigaze_ed25519 -L 8080:localhost:8080 pigaze@pigaze.local
```

Пока сессия открыта, отладочная страница — <http://localhost:8080>: живой ИК-кадр
(жёлтое — окна глаз, красное — зрачок, зелёное — блики диодов), увеличенные глаза,
состояние и кнопки «Калибровка» / «Пауза». Страница слушает только localhost Pi,
потому что показывает твоё лицо.

На Pi:

```bash
journalctl -u pigaze -f            # лог: к/с, % кадров с глазами, режим, взгляд
pigaze-ctl calibrate               # toggle | pause | resume
sudo nano /etc/pigaze/pigaze.conf  # настройки, затем: sudo systemctl restart pigaze
pigaze --snapshot /tmp/f.pgm       # один кадр с камеры (при остановленной службе)
pigaze --selftest                  # проверка трекера на синтетике, без камеры
```

Пароля у пользователя `pigaze` нет — вход только по SSH-ключу. Нужен пароль для
консоли: `sudo passwd pigaze`.

## Настройка по месту

* **Фокус.** `lens_position = 1.7` — это 60 см (диоптрии = 1 / метры). Сидишь на 50 см → 2.0,
  на 70 см → 1.4. Смотри на увеличенные глаза на отладочной странице: зрачок должен быть резким.
* **Экспозиция.** По умолчанию авто. Если блики не белые или зрачок не чёрный:
  `shutter_us = 8000`, `gain = 4` и подстрой.
* **Очки** дают большие блики; они отфильтровываются (`glint_max_area`), но могут закрыть зрачок.
  Помогает наклон бара, чтобы отражение ушло вбок.
* **Курсор дрожит** → уменьши `filter_min_cutoff` (0.4). **Отстаёт** → увеличь `filter_beta` (3–4).

## Сборка и тесты

На Pi это делает установщик (`deploy/pi-setup.sh`): ставит `g++`, если нет, собирает, гоняет
модульные тесты и `--selftest`, ставит службу. Повторный запуск безопасен:

```bash
sudo bash /opt/pigaze/src/deploy/pi-setup.sh
```

На Windows-ПК (MSVC из Visual Studio) собираются и проверяются переносимые модули:

```bash
software/build_tests_windows.cmd
```

## Устройство

```
include/pigaze/, src/core/   переносимое ядро (тестируется на ПК и на Pi)
  eye_detector   зрачок (тёмный) + блики ИК-диодов в окне глаза, субпиксельный центр
  tracker        поиск пары глаз по бликам во всём кадре, слежение, моргания
  gaze           вектор «зрачок - блик» / межзрачковое расстояние -> полином 2-й степени
  calibration    9 точек курсором, медианы, проверка RMS
  filter         One Euro (без дрожи на фиксации, без задержки на скачках), dwell
  controller     режимы: нужна калибровка / калибровка / слежение / пауза
  ch9329         кадры протокола CH9329, абсолютная мышь 0..4095
  config, debugview, synth, image, linalg
src/linux/        rpicam-vid (кадры через pipe), UART, кнопка питания, FIFO, HTTP
src/main.cpp      сборка всего в цикл
deploy/           systemd-службы, установщик, logind (кнопка питания), pigaze-ctl
```

## Подключение (Pi 5, 40-pin)

| Pi | Куда |
|---|---|
| pin 1 (3.3 V) | CH9329 VCC (модуль на 3.3 В — тогда и его TX 3.3 В, безопасно для Pi) |
| pin 6 (GND) | CH9329 GND |
| pin 8 (GPIO14, TX) | CH9329 **RX** |
| pin 10 (GPIO15, RX) | CH9329 **TX** |
| pin 12 (GPIO18) | база ключ-транзистора ИК-диодов (через ~1 кОм) |
| pin 2/4 (5 V) | питание ИК-диодов через 180 Ω |

USB CH9329 — в ПК. Камера — в любой из разъёмов CAM/DISP.
